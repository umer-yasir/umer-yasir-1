# Setup

1. Create a **public** repository named exactly `umer-yasir` under the GitHub account `umer-yasir`.
2. Upload this repository structure to `umer-yasir/umer-yasir`.
3. Open **Actions → GitHub-Profile-3D-Contrib → Run workflow** once.
4. After the workflow generates `profile-3d-contrib/`, the README will display the night-view contribution city.
5. If you change an SVG and GitHub appears to show an old version, increment `?v=1` in README to `?v=2` and commit the SVG before the README.

The custom SVGs intentionally avoid external images, JavaScript, and external font loading so they remain self-contained.
